
# 🚦 Road Accident Analysis Dashboard


## 📌 Overview
This project analyzes road accident data to identify high-risk locations, causes, and trends. The interactive dashboard provides actionable insights for improving road safety.


## 🎯  Features
- **Severity Trends Analysis:** Tracks accident severity patterns over different time periods.
- **Cause Analysis:** Identifies common factors contributing to accidents, such as weather, road conditions, and driver behavior.
- **Interactive Visualizations:** Provides dynamic charts, graphs, and maps for deeper insights.
- **Customizable Filters:** Allows users to filter data based on location, time, severity, and contributing factors.


## 🔧 Tools & Technologies
- **Power BI** (DAX, Power Query, Maps)
- **Excel**

## 🔍 Expected Insights
- **Severity Trends:** Analyze accident severity patterns.
- **Common Causes:** Highlight major contributing factors.
- **Time-Based Trends:** Examine peak accident periods.
- **Geographic Risk Assessment:** Evaluate accident density by area.
- **Demographic Impact:** Assess age, experience, and behavior influences.
- **Traffic & Infrastructure Effects:** Measure congestion and road conditions impact.
- **Safety Recommendations:** Suggest actionable improvements.
